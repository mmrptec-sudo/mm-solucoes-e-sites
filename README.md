# MM Soluções e Sites — primeira versão visual

Esta é uma primeira versão estática do site institucional e da tela de entrada do portal.

## Arquivos
- `index.html`: site institucional
- `portal.html`: prévia visual da área do cliente
- `styles.css`: estilos responsivos e identidade visual azul
- `script.js`: menu mobile e ano do rodapé

## Antes de publicar
1. Troque o número de exemplo do WhatsApp em `index.html` pelo número oficial da MM, com código do país e DDD.
2. Revise os preços e os serviços dos planos.
3. Inclua os dados reais de contato e os projetos do portfólio, com autorização dos clientes.
4. O login em `portal.html` é apenas uma demonstração visual. Ainda não existe autenticação nem banco de dados.
5. Para o portal real, configurar Supabase Auth, tabelas, políticas RLS e convites administrativos. Não armazenar senhas manualmente.

## Publicação
O projeto pode ser enviado para um repositório GitHub e importado na Vercel como site estático.
